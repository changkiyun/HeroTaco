## 프로젝트 개요

Pick A Lunch는 교내 맛집 공유 서비스 어플리케이션으로 개발되었습니다.
인증된 학교 구성원들 간에 맛집을 공유함으로써 정보의 신뢰성을 높이고 구성원들 간에 커뮤니티로써 기능할 수 있습니다.

Java 기반으로 개발된 Android Native 어플리케이션과 Firebase로 만들어진 Serverless 구조로 구현되었습니다.

<br>

**프로젝트 이름**: Pick A Lunch

**프로젝트 소개**:  대학내 맛집 공유 커뮤니티

**프로젝트 기간**: 2022.08. ~ 2022.12. (4개월)

**프로젝트 인원**: Android(4)
