## 프로젝트 개요

여기타코는 공공데이터 API와 NaverMapAPI를 활용한 푸드트럭 제보 서비스 입니다.

사용자가 지도에 위치를 지정해 마커로 표시하고 해당 위치의 푸드트럭 정보를 확인할 수 있습니다.

Java 기반으로 개발된 Android Native 어플리케이션과 Firebase로 만들어진 Serverless 구조로 구현되었습니다.

<br>

**프로젝트 이름**: HereTaco

**프로젝트 소개**: 공공데이터 API와 NaverMap API를 활용한 푸드트럭 제보 서비스

**프로젝트 기간**: 2023.11. ~ 2023.12. (1개월)

**프로젝트 인원**: 개인프로젝트

## 주요 기능

### 푸드트럭 제보
<img src="https://github.com/user-attachments/assets/93cac5ab-22d9-4466-9af1-e186d67238bf" width="250"/>
<p> 사용자가 푸드트럭을 발견하면 지도상에서 위치를 지정하고 푸드트럭을 제보할 수 있습니다.

### 사용자 마커
<img src="https://github.com/user-attachments/assets/3c6d2bed-7732-4970-b697-dd285791071a" width="250"/>
<p> 사용자가 푸드트럭 위치를 제보하면 지도에 음식모양 마커가 생성됩니다.

### 꼬치트럭
<img src="https://github.com/user-attachments/assets/b9e0f254-00af-480e-b818-8ad892c30996" width="250"/>
<p> 사용자가 등록한 마커를 클릭하면 전화번호, 영업시간, 영업일, 주소를 확인할 수 있습니다.

### 공공데이터 API
<img src="https://github.com/user-attachments/assets/f58d8bc7-5252-4a7a-9e04-8ebfacbb0fc6" width="250"/>
<p> 공공데이터 API를 기반으로 서울시내 휴게음식점으로 등록된 매장을 마커로 표시합니다.

### 매장 정보
<img src="https://github.com/user-attachments/assets/589cd4d4-8b38-42fc-a1cb-8318fb9fc9f3" width="250"/>
<img src="https://github.com/user-attachments/assets/8b16e9f4-2d30-40bc-b21c-6dbd06dbdc6f" width="250"/>
<p> 마커를 클릭하면 공공데이터에 등록된 매장이름, 전화번호, 주소 등을 확인할 수 있습니다.
